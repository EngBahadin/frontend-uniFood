# Uni Food Frontend

Welcome to the Uni Food frontend project! This application is built with **TypeScript** and **Next.js**. Follow the steps below to set up and run the project locally.

## Prerequisites

Before you begin, ensure you have the following installed on your machine:

- **Node.js** (version 14.x or later)
- **npm** (comes with Node.js)

You can download Node.js from [here](https://nodejs.org/en/download/).

## Clone the project

1. Open your terminal and clone the repository:

```bash
git clone https://github.com/EngBahadin/frontend-uniFood.git
```

### Go to the project directory

```bash
cd .\frontend-uniFood\
```
Install the project dependencies:
```bash
npm install
```
Run the project locally at http://localhost:3000
```bash
npm run dev
```
### Running the Application

If you experience slow performance while using the development server with `npm run dev`, you can build and run the project in production mode for improved speed.

#### To run the project in production mode:

1. **Build the application:**

```bash
npm run build
```
2- **Run the application:**
```bash
npm start
```
